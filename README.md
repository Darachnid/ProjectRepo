# Pebble Time 2 app projects

## Taskwarrior companion

The initial Pebble Time 2 (Emery) Taskwarrior app is in [`pebble-taskwarrior/`](pebble-taskwarrior/README.md).

- Watch UI: current task, urgency-sorted task list, action menu, and context selector.
- Pebble phone Settings: Tailnet hostname, optional API URL/token, route configuration, theme, accent color, and optional-field visibility.
- Integration note: the portal and TaskChampion sync hostnames are known, but the live REST API contract still needs verification. See [`pebble-taskwarrior/docs/api-contract.md`](pebble-taskwarrior/docs/api-contract.md).

Build from a Rebble/Pebble SDK 3 environment with Emery support.
